# Gobierno de datos

No introduzca datos personales reales en este prototipo. Antes de procesarlos se requiere: base legal/autorización y finalidad documentada; minimización; controles de acceso; plazos de retención y borrado; atención de derechos de titulares; registro de auditoría; evaluación de sesgo; revisión humana y canal de impugnación. Los CSV de entrenamiento y prueba están excluidos de Git. Los logs de la API no incluyen payloads financieros ni de solicitantes.
